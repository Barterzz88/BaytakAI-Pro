# BaytakAI Pro - Phase 2 (Broker & Admin, Supabase Storage, Refresh Tokens)

This repository is an enhanced version of BaytakAI with:
- Role-based auth (USER, BROKER, ADMIN)
- Refresh tokens for long sessions
- Leads system (contact inquiries)
- Image uploads to Supabase Storage (directly from frontend using signed URLs)
- Admin dashboard to approve listings
- Gemini endpoints for AI-generated descriptions & parsed searches

Follow the included instructions to deploy on GitHub, Supabase, and Vercel.
